This portfolio connects Hannan Noor’s projects, technical interests and community work. The network relationships reflect technologies documented in the linked project repositories.

Design and development

A custom editorial layout and deterministic 3D network. Round project previews stay facing the viewer, preserving the original images as the network orbits. Selecting a node highlights its connections while keeping the wider network visible. Project details include full-size screenshots and documentation figures.

Open source

  • Three.js r180 and OrbitControls, MIT licence. Read licence.
  • PyaesoneP’s neural-network portfolio inspired the connected-network concept. The network implementation here is custom, rather than copied from that repository.
